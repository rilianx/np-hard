# De los problemas NP-hard a las aplicaciones actuales

Guía didáctica en español basada en el esquema «Eighteen Reductions» de Tim Roughgarden.

## Documento PDF

- [Ver la guía en GitHub](docs/Guia_NP_Hard_18_reducciones.pdf)
- [Descargar el PDF](https://github.com/rilianx/np-hard/raw/refs/heads/main/docs/Guia_NP_Hard_18_reducciones.pdf)

La guía tiene **28 páginas** e incluye los **19 problemas** conectados por las **18 reducciones** del esquema.

Para cada problema se explican su descripción, entradas y salidas, un ejemplo, aplicaciones actuales, cómo aprovechar un algoritmo y una pregunta para clase. También incluye una explicación de las reducciones, tres ejemplos de modelado, estrategias prácticas, una actividad integradora y referencias.

- [Ver el PDF](docs/10_aplicaciones_reales_NP_Hard.pdf)

Documento de **17 páginas** con diez casos detallados: reparto de medicamentos, turnos hospitalarios, cómputo, pruebas de software, servicios de emergencia, configuración de productos, horarios universitarios, producción, campañas en redes y conservación ambiental.

Cada caso desarrolla datos, variables, restricciones, objetivo, un ejemplo numérico, la combinación de problemas fundacionales, una justificación de dificultad y consideraciones prácticas. Incluye una actividad, **11 referencias específicas vinculadas a los casos** y cuatro referencias generales. La bibliografía indica qué respalda cada fuente y ofrece DOI y enlaces; los escenarios y ejemplos numéricos fueron elaborados para la guía.

## Propósito

Ayudar a estudiantes a reconocer estructuras comunes entre problemas de horarios, selección de proyectos, cobertura, difusión, planificación de trabajos y rutas, y entender cómo aprovechar algoritmos para problemas fundacionales en aplicaciones nuevas.

Las aplicaciones son ilustrativas. Las reducciones se presentan a nivel conceptual y no sustituyen demostraciones formales.
